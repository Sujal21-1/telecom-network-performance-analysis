Dataset Overview

The Telecom Network Dataset contains network performance information recorded across telecom towers and time periods.

The dataset includes network usage, performance, environmental, and congestion-related information.

Columns
timestamp — Date and time of the network log.
tower_id — Identifier for the telecom tower.
users_connected — Number of users connected to the tower.
download_speed — Average download speed measured in Mbps.
upload_speed — Average upload speed measured in Mbps.
latency — Network latency measured in milliseconds.
weather — Weather conditions at the time of the network measurement, including Clear, Rain, Snow, and Storm.
congestion — Binary indicator showing whether network congestion occurred, where 1 indicates congestion and 0 indicates no congestion.
