Telecom Network Performance Dashboard

Overview

This Power BI dashboard provides an overview of telecom network
performance, user connectivity, network demand, congestion, latency, and
download speeds. It is designed to help identify network conditions,
compare network towers, and understand how performance varies across
time and weather conditions.

Dashboard Analysis

1. Network Demand Over Time

The line chart tracks average users connected over time. Network demand
fluctuates throughout the period, with several noticeable peaks and
declines. This helps identify periods of higher network usage and
potential capacity concerns.

2. Congestion Rate by Hour

The hourly congestion chart shows how congestion changes throughout the
day. Congestion varies by hour, with some periods showing substantially
higher rates than others. These patterns can help identify hours where
network resources may experience greater pressure.

3. Network Latency by Hour

Average latency is shown across the 24-hour period. The chart
demonstrates noticeable hourly variation, with latency generally
remaining around the 100--112 range and several spikes and dips
throughout the day.

4. Congestion Rate by Network Tower

The tower comparison shows differences in congestion across five network
towers. Tower 4 has the highest congestion rate among the towers
displayed, while Tower 3 has the lowest. This comparison can help
prioritize network optimization and infrastructure improvements.

5. Download Speed vs. Network Latency

The scatter plot compares average download speed with average latency.
It provides a quick way to evaluate whether faster download performance
is associated with lower or higher latency across the observed network
conditions.

6. Download Speed by Weather Condition

Average download speed is compared across Rain, Storm, Clear, and Snow
conditions. Rain shows the highest average download speed in the
dashboard, while Snow shows the lowest. The relatively small differences
suggest that download performance remains fairly consistent across the
weather categories represented.

Key Takeaways

The network supports approximately 2 million connected users.

Average download speed is approximately 52.09, while average
upload speed is approximately 25.17.

Overall congestion is approximately 5.63%.

Network demand changes considerably over time, indicating varying
levels of network utilization.

Congestion differs across network towers, with Tower 4 showing the
highest rate among the towers displayed.

Hourly latency fluctuates throughout the day rather than remaining
constant.

Download speeds are relatively close across the four weather
conditions, although Snow has the lowest average shown.

Business Value

This dashboard can support telecom network teams by making network
performance easier to monitor and compare. The insights can be used to
identify periods of high demand, locate towers with higher congestion,
monitor latency patterns, and evaluate network performance under
different conditions.

Project Purpose

The goal of this project is to transform telecom network data into an
interactive business intelligence dashboard that communicates network
performance clearly and supports data-driven operational decisions.
